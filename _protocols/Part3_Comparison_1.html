Part 3 of 3 — Protocol Reference

PhIP-Seq vs MIPSA

Side-by-side comparison of technology, variability profile, and analytical implications

Technology Overview

PhIP-Seq

  • Phage display: peptide tiles expressed on T7 bacteriophage surface
  • Library: overlapping peptide fragments, 36–56 aa (length increased v1→v2)
  • Barcode = phage genome insert — genotype and phenotype physically linked on phage particle
  • Prokaryotic expression system — no post-translational modifications
  • Linear epitopes only — phage capsid prevents access to conformational epitopes
  • Mature technology: full Nature Protocols paper, video supplement, community-validated pipelines

MIPSA

  • Cell-free expression: full-length proteins synthesised in solution
  • Library: full-length ORFs (HuSIGHT) or peptide tiles (VirSIGHT)
  • Barcode = UCI cDNA covalently linked to protein via HaloTag/HaloLigand self-assembly during translation
  • E. coli cell-free system — limited post-translational modifications but folding possible
  • Conformational epitopes accessible — proteins are soluble and unconstrained
  • Newer technology: primary papers published 2021–2022; Infinity Bio commercial service ongoing

The Probe-Aggregation Data Structure — How It Differs Between Technologies

PhIP-Seq
  • Multiple overlapping tiles cover the same protein region — implicit redundancy, not by explicit design
  • Tiles covering the same epitope are positively correlated; tiles from different regions of the same protein are probing distinct potential epitopes
  • Aggregation across tiles is not formally modelled — confirmation is a post-hoc rule requiring tile overlap to agree
  • Tile-level efficiency differences driven by synthesis bias, cloning loss, and phage display constraints
MIPSA (Full-Length ORFeome Library)
  • ~10 UCIs per ORF by explicit design — each is an independent barcoded copy of the same full-length protein
  • UCIs are probing the same target, not different epitopes — closer to the classic microarray multi-probe structure
  • UCI-level efficiency variation is driven by cis vs trans coupling rate (B3) — a function of ORF size and HaloTag maturation kinetics
  • This is the direct structural analogue of the RMA probe-aggregation problem: same target, multiple imperfect probes, known efficiency variation
Key Differences — Biology and Statistics

Biological Differences

  • MIPSA detects antibodies against conformational epitopes; PhIP-Seq does not — this is the most consequential biological difference for autoimmunity applications
  • PhIP-Seq peptide tiles can include post-translational modification variants (citrullination, phosphorylation) if the modified peptide is synthesised — MIPSA full-length proteins expressed in cell-free system lack most PTMs
  • PhIP-Seq library content is constrained only by DNA synthesis and cloning — virtually any antigen can be included; MIPSA ORFeome requires a source clone library
  • MIPSA background is partly determined by the trans-coupling rate (~50%) — an irreducible biological noise floor from the self-assembly mechanism
  • PhIP-Seq background is partly determined by phage non-specific sticking and E. coli cross-reactive antibodies — structurally different noise sources

Statistical Differences

  • Both technologies produce count matrices with the same statistical distribution family (negative binomial, overdispersed) — core statistical framework is shared
  • MIPSA has explicit, designed-in probe redundancy (~10 UCIs/ORF); PhIP-Seq has implicit redundancy (overlapping tiles) — MIPSA's structure maps more cleanly to a formal probe-aggregation model
  • PhIP-Seq tile-level efficiency variation has multiple drivers (synthesis, cloning, phage display) — harder to model than MIPSA UCI variation, which has a more defined mechanistic source (cis-coupling rate)
  • An RMA-like probe-aggregation model in the negative binomial family applies to both technologies but is more directly motivated by MIPSA's explicit multi-UCI design
  • Both technologies currently use per-probe, per-test inference (edgeR/BEER/Z-score) — neither has a published probe-aggregation model
  • FDR-based inference at scale is a shared limitation — the statistical concerns about p-values and q-values apply equally to both
Current Statistical Methods — Shared Framework

edgeR

Negative Binomial Model
Compares read counts per tile/UCI against mock IPs using a two-group negative binomial GLM with empirical Bayes dispersion estimation. Default method for MIPSA. One of three main methods for PhIP-Seq.

BEER

Bayesian Hierarchical Model
Produces posterior probabilities of enrichment and fold-change estimates. Greater sensitivity for weakly reactive peptides vs edgeR. Used in PhIP-Seq; also applicable to MIPSA. Includes an edgeR pipeline for convenience.

Z-score

Non-parametric Enrichment
Z = (RPM_sample − mean RPM_mock) / SD RPM_mock. Threshold typically Z > 3.5. Simpler and more transparent than model-based methods. Used primarily in PhIP-Seq (DeRisi lab). Less sensitive for weak reactivities.
